# Security Policy

## Supported Versions

Security fixes are applied to the latest release and to the `main` branch. Older releases do not receive fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public issues, discussions, or pull requests.

Report them privately through GitHub: open the **Security** tab of the Networking repository and choose **Report a vulnerability** to create a private security advisory.

Include a description of the issue, the affected version or commit, and steps to reproduce it if possible.

## Handling

Reports are reviewed privately. If the issue is confirmed, a fix is prepared and released, and the advisory is published once a fixed version is available. Reporters are credited in the advisory unless they prefer to remain anonymous.
